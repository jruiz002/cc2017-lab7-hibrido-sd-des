# Anexo: línea base generada por una IA (Task 1.3)

Esta carpeta guarda, **sin modificar**, lo que una IA externa entregó cuando le dimos el
modelo completo del laboratorio sin pistas sobre eventos de estado, conservación ni
sensibilidad a la ventana.

El contenido se agrega tal como se recibió (no se edita después):

- `prompt.md`: prompt exacto que se le dio a la IA.
- `codigo_original.py`: código tal como lo entregó.
- `respuesta_ia.md`: respuesta completa (texto y código).
